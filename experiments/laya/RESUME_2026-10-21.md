# Laya 재개 검증 — 2026-10-21

**의존성 설치는 성공, 공식 모델 접근은 차단, 실제 모델 평가는 미실행. 운영 교체는 비활성 유지.**

이 문서는 README의 2026-10-20 미설치·미게시 상태를 갱신한다. 기존 구현 `da1094220720673fab2aa35237f1112266f9b22f`와 로그 전용 `960f1eb0261ad1739907b96e85b2a0f9ce16e938`는 모두 유지하며, 후자는 이번 재개에서 origin 게시에도 성공했다. PR24/54는 수정하지 않는다.

## 완료 및 실제 확인

- 공식 PyPI JSON 최신 Laya 버전은 여전히 0.4.12. 공식 wheel 436,585바이트를 다운로드하고 SHA256 `485625629bf14003e947ce13e5f901cc1ba8d298a152e52917b19017914baf80`을 대조했다. 이 wheel의 `Agent`, `system_one`, `build_model`, tokenizer/safetensors 로딩과 잘림 보고 경로를 직접 확인했다. 별도 셸 설치 스크립트나 `trust_remote_code=True`는 실행하지 않았다.
- 공식 PyPI와 공식 PyTorch CPU wheel registry만 사용해 전체 의존성 버전·해시 lock을 생성하고 별도 `/tmp/laya-venv`에 wheel만 설치했다. CPython 3.12 / Linux x86_64 전용이며 ARM64에서 이 lock을 재사용하지 않는다. 핵심 버전은 Laya 0.4.12, PyTorch 2.8.0+cpu, Transformers 4.57.6이다. 모델 실행 호환성은 가중치가 없어 아직 검증되지 않았다.
- 실제 패키지 import와 공식 `Agent.system_one` API 서명 확인 성공. 설치·import 증거와 제한된 환경 정보는 `resume-evidence.json`에 저장했다. import-only RSS/시간은 모델 RAM/추론 시간과 다르다.
- TypeScript/Jev 회귀 테스트 40건, Python 가드·형식 검증 10건 통과. 변경 TypeScript ESLint와 프로젝트 `tsc --noEmit` 통과.
- 실제 설치된 Laya `build_sequence`를 합성 문자 토크나이저와 긴 한국어 입력으로 실행해 1024 잘림 보고와 8192 보존을 검증했다. 이는 실제 multilingual 토크나이저·모델 검증이 아니다. 입력 크기 초과, 모델 보고의 잘림·선택지 붕괴, 잘못된 ID/점수/합계, 타임아웃은 모델 결과를 사용하지 않는다. TS의 희소 배열 점수도 거부한다.
- 기존 공개 저장소 `src/content/key-cases-data.ts`의 판례 3건 요약을 후보로 더해 조문/판례 관련성 fixture 총 6건을 준비했다. 판례 원문 검증이나 최신 법리 검증을 한 것이 아니며, 라벨은 작은 실험용 관련성 라벨이다. 법률 정답 검증 성능으로 해석하지 않는다.

## 현재 차단과 미측정

명시적 재개 후 공식 HF 모델 API `https://huggingface.co/api/models/convaiinnovations/laya-multilingual`에 한 번 재시도했으나 `Tunnel connection failed: 403 Forbidden`으로 거부됐다. 우회·미러·개인 토큰·새 인증을 사용하지 않았고 반복 다운로드하지 않았다. 공식 가중치 다운로드, 실제 multilingual 토크나이저 실행 및 모델 추론은 0건이다. 한국어 관련성 정확도, 순위 개선, 실제 추론 p50/p95, 모델 RSS는 모두 미측정이다. `result-unconfigured.json`과 `result-refused-unverified-snapshot.json`은 각각 미설정·미검증 snapshot의 안전한 복귀 기록이다.

모델 revision은 공식 Laya wheel의 reviewed SHA `e4e9ddf21a7b1903b7acffd8814ad4307bf63a67`로 유지했다. HF 접근이 막혀 현재 저장소 메타데이터와 가중치 SHA256을 직접 대조하지 못했다. 따라서 디렉터리 이름만으로 공식 모델이라 믿지 않도록, 이제 실행에는 별도 **검토된 manifest**가 필수다. manifest에는 repository, revision, 모든 허용 artifact의 SHA256을 기록해야 하며 공식 고정 snapshot과 독립 대조한 후 사용해야 한다. 임의 로컬 파일에서 자체 생성한 manifest는 공식 출처 검증이 아니다. 확인되지 않은 모델 해시를 만들어 저장하지 않았다.

manifest는 모델 디렉터리 바깥 JSON 파일이며 형식은 `{"repository":"convaiinnovations/laya-multilingual","revision":"e4e9ddf21a7b1903b7acffd8814ad4307bf63a67","files":{"model.safetensors":"<공식 artifact와 대조한 SHA256>","rl_agent_config.json":"<SHA256>","encoder/config.json":"<SHA256>","tokenizer/tokenizer_config.json":"<SHA256>","tokenizer/tokenizer.json":"<SHA256>"}}`이다. 실제 배포 snapshot에 존재하는 tokenizer 파일은 모두 포함한다. 가중치는 safetensors만, encoder는 config.json만, tokenizer는 json/txt/model 파일만 허용한다. 미등재 artifact와 중첩 auto_map 설정을 거부한다. 소스·해시를 검토한 최소 snapshot만 입력해야 한다.

## 재현 명령

```sh
uv venv /tmp/laya-venv --python 3.12 --cache-dir /tmp/laya-uv-cache
uv pip sync experiments/laya/requirements-linux-x86_64-py312.lock \
  --python /tmp/laya-venv/bin/python --require-hashes --only-binary :all: \
  --torch-backend cpu --default-index https://pypi.org/simple --cache-dir /tmp/laya-uv-cache
/tmp/laya-venv/bin/python -m unittest discover -s experiments/laya -p 'test_*.py'
/tmp/laya-venv/bin/python experiments/laya/evaluate.py
```

공식 접근이 복구되고 pinned artifacts/manifest 대조가 끝난 후에만:

```sh
/tmp/laya-venv/bin/python experiments/laya/evaluate.py \
  --snapshot /path/to/snapshots/e4e9ddf21a7b1903b7acffd8814ad4307bf63a67 \
  --manifest /path/to/reviewed-manifest.json --repeats 3 --timeout 30
```

평가는 사례별 CPU cold-process·load·첫 추론·이후 warm 반복 지연과 peak RSS, 관련성 top1/MRR/recall@3 및 순위 변화를 분리한다. 현재 6개 fixture/기본 3회 반복은 smoke 수준이며 운영 승인 근거로 부족하다. 실제 모델 결과가 생기면 검수된 더 큰 공개 법령·판례 정답지, 동일 후보 순서 및 후보 순서 교란, 답이 뒤쪽에 있는 긴 조문, 동시 요청/메모리 측정을 추가해야 한다. 실패 사례는 Laya 정확도로 계상하지 않으며 실패율도 함께 검토해야 한다. 기존 Jev 유료 API 비교는 실행하지 않았다.

## 실행 환경과 운영 범위

이번 cloud sandbox는 x86_64, CPU quota 4 cores 상당, cgroup 메모리 16GiB다. 사용자 Oracle server1(1 OCPU/6GB)·server2(2 OCPU/12GB)에 설치하거나 측정하지 않았다. ARM64 CPU 지원 가능성과 이 x86_64 lock의 플랫폼 제한은 별개이며 GPU가 필수라는 결론도 내리지 않는다. Oracle 실시간 여유 자원·SSH 접근은 미확인이다. 새 서버·유료 자원·보안 설정·지속 인증은 생성하지 않았다.

실제 모델 관련성·지연·RSS·회귀 검증이 끝나지 않아 운영 전환은 승인 조건을 충족하지 못했다. FAQ/법령/판례 운영 호출부와 Jev 활성 플래그는 그대로다. 로컬 score bridge는 아직 연결하지 않았으며 이 PR은 실험 준비물과 실패 처리 검토용이다. Laya는 검색 후보 결정 엔진이며 법률 정답 검증기가 아니다.
