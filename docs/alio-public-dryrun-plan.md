# ALIO 공개 규정 드라이런 준비

상태: 실제 ALIO 원본 미확보·미실행. 합성 E01 검증과 별도 작업이다. 저장소의 docs/data/tests/scripts 및 취업규칙 경로에서 ALIO 링크·기관·규정명·개정일·해시가 함께 있는 fixture나 계획은 찾지 못했다. 기존 docs/work-rules-ac-compare.md는 고용노동부 표준취업규칙 2023/2025 공개 자료를 다루며 ALIO 표본으로 간주하지 않는다. 실제 회사 규칙을 시험했다는 코드 주석도 원본 provenance가 없어 ALIO 완료 증거가 아니다.

## 원본 확보 후 고정할 입력

기관명, 규정명, ALIO 공시 페이지 URL, 공식 첨부 URL, 공시일, 문서에 표시된 최종 개정일·시행일, 파일명/형식, 실제 바이트 수/SHA256, 확보 시점, 공식 공개자료 여부를 manifest에 기록한다. 공시일을 개정일로 대체하지 않는다. 파일·본문 불일치나 날짜 미상은 미확정으로 둔다. 원본은 불변 보관하고 추출·변환본은 별도 파일과 해시, 사용 도구/버전/명령, 원본 해시를 연결한다. 합성 재포장이나 모델 생성 텍스트를 실제 규정으로 표시하지 않는다.

## 현재 프로그램의 실제 경계

- /tools/work-rules → WorkRulesClient → RulesCheck: DOCX/HWPX를 브라우저 안에서 추출하고 텍스트 붙여넣기를 제공한다. 10MB 한도, 빈/이미지 문서 오류, 입력 보존과 재시도는 기존 tests/layout/period-integration.mjs에 검사가 있다.
- PDF·구형 HWP는 이 화면의 지원 파일 입력이 아니다. 원본 파일 거부 안내를 검증한다. PDF 텍스트층은 비과금 로컬 pdftotext 파생본을 검증한 뒤 붙여넣기 경로로 검사할 수 있으나 PDF 직접 업로드 성공으로 보고하지 않는다. 구형 HWP 변환은 지원 도구 확보 전 차단이다. OCR/vision 유료 API로 전환하지 않는다.
- splitArticles/matchArticles/periodCheck(src/lib/laws/standard-check.ts): 실제 추출본문과 로컬 public/data/laws 데이터를 사용한다. 표준 문서·규칙·개정 이벤트 데이터의 버전/해시, matcher 버전, 기간을 결과에 고정한다. 자동 매칭을 전문가 정답으로 표시하지 않는다.
- RulesCheck 결과의 신구대조 Word/Excel/HTML 다운로드를 실제 bytes로 검사한다. 이 취업규칙 흐름은 E01의 Word/PDF 흐름과 동일한 기능이 아니다. PDF를 추가 요청하면 현재 HTML/print 지원 여부부터 구분한다.
- ObservationCapture는 관리자 전용이며 준비 상태가 아닐 때 비활성이다. 실제 인증정보를 읽거나 저장하지 않는다. 일반 사용자 결과/보완은 로컬에서 확인하고, 오탐 기록 UI는 합성 관리자 affordance 및 mock HTTP 응답으로만 검사한다. 운영 저장·RLS·권한 통과를 주장하지 않는다.

## 실제 표본으로 실행할 순서와 통과 기준

1. 공식 원본 metadata/size/SHA256 대조. 부모가 확보한 공식 source/ref를 재사용하며 파일이나 URL을 추정하지 않는다.
2. 지원형식이면 실제 파일을 file input에 올려 textarea 추출값·문단/제N조 경계·표/각주/부칙을 원본과 대조. 예상 원문 조항을 수동 고정해 누락/중복/페이지 머리말 유입을 검사한다. PDF/HWP 파생본은 별도 경로로 기록한다.
3. 원본 개정일과 검토 기준일을 명시해 조항 매칭/변경사항을 실행. 대표 정확 매칭·모호 매칭·잘못 매칭·미매칭을 구별하고 source 조항 번호/본문 근거를 남긴다. 손실된 추출을 법률 오탐으로 오인하지 않는다.
4. 오탐 후보를 표시하고 로컬 수정본으로 재점검. 최초 결과/수정 후 결과 및 수정 이유를 각각 보존한다. 개정일/본문 변경으로 새 run이 생성되고 예전 result/observation을 재사용하지 않는지 확인한다. 관리자 저장은 mock only, 본문이 API로 나가지 않는지도 검사한다.
5. Word/Excel/HTML 등 실제 제공 출력 파일을 열어 규정명/기간/원문·제안문·근거·누락 여부를 확인한다. 가능하면 비과금 로컬 렌더러로 검증한다. 자동 제안문을 확정 개정본으로 표시하지 않는다.
6. 데스크톱/모바일: 실제 파일 → 텍스트 → 기간 → 조항/판정 → 오탐/보완 → 재실행 → 결과 출력. 외부 요청과 provider API, 운영 DB를 차단한다. 데이터 로딩은 로컬 실제 법령 파일, 모델 판정이 필요하면 명시적 mock으로만 처리한다.

## 결과 보고 분리

원본 확보/추출 정확도, 프로그램 매칭/UX/E2E, 모델(mock/live), 공식 법령 시행시점 확인, 전문가 법률 검토를 별도 상태로 보고한다. 확인된 ALIO 표본에서만 수치와 결과를 산출하며 표본이 없으면 미실행으로 둔다. 실제 ALIO 원본 및 정확한 규정 개정일·형식 확보가 첫 완료 단위의 현재 선행조건이다. E01 합성 테스트 579건은 ALIO 실제 문서 테스트 결과가 아니다.

유료 AI 호출·운영 DB 실행·권한/키 변경·배포 없이 진행한다. 기존 PR35/36 관측·법령 매칭 변경은 보존하며 실제 파일의 provenance 확인 전에 매칭 규칙을 임의 보정하지 않는다.
