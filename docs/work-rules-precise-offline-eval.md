# 정밀 점검의 추가 효용을 비교하는 오프라인 평가

유료 모델 비교 실험은 실행하지 않았다. 현재 작은 정답지만으로 AI의 추가 효용이나 법률 정확성을 입증할 수 없다. 아래 평가는 저장된 결과를 비교하는 도구이며 법률 정답을 생성하지 않는다.

## 입력과 실행

기존 `comparison.v1`의 `rows` 형식을 유지한다. 동일 문서·기간·사업장 인원에 대한 규칙만 결과와 규칙+AI 결과를 각각 준비한다. 규칙 결과를 AI가 만든 결과로 대체해서는 안 된다. 법률 전문가가 별도로 확인한 지적 항목을 `gold.items`, 지적하면 오탐인 항목을 `gold.negatives`에 기록한다. 미표기 항목은 오탐으로 단정하지 않고 `unlabelled`로 보고한다. 고객 문서와 실제 정답지는 로컬에 보관한다.

```sh
python3 scripts/work_rules_c/eval.py --baseline rules-only.json --pred rules-plus-ai.json --gold gold.json
```

출력은 각 방식의 탐지·누락·불이익변경 누락, 새로 찾은 항목, 사라진 항목, 추가 오탐, 미완료·충돌·미검증 인용이다. 누락·퇴행·추가 오탐이 있으면 종료 코드 1이다. `legal_accuracy_proven`은 항상 false다. 합성 테스트는 비교기 동작만 검증하며 모델의 효용 평가가 아니다.

## 검수자가 채울 평가 항목

| 구분 | 필요한 대비 자료 | 확인할 실패 |
|---|---|---|
| 기존 규칙 유지 | 기존 키워드·수치 신호가 있는 합성 조문 | AI가 규칙 지적을 지우는지 |
| 의미상 추가 효용 | 정족수·재심 인원이 사업장 인원과 맞지 않는 합성 사례 | 규칙 누락을 AI가 보완하는지, 전문가 확인 필요 |
| 불이익변경 | 종전과 개정안, 유리한 예외·조건을 가진 사례 | 단순 수치보다 조건·예외를 놓치는지 |
| 비지적 대조군 | 예외 때문에 문제가 없는 것으로 검수한 사례 | AI의 추가 오탐·불필요한 수정 초안 |
| 법령 근거 | 법령명·조문·시행일·저장 원문·원문 링크 | 없는 인용, 시행 전후 혼동, 근거 없는 완료 표시 |
| 미완료와 충돌 | 한 회차 실패, 조문 일부 누락, 서로 다른 의견 | 정상 응답이 실패·충돌을 지우는지 |
| 추출·저장 | 중복 번호 3개 이상, 중첩표·다만 문구, 부분 변경 | 본문 누락, 다른 위치 변경, 비수정 영역 손실 |
| 검수 부담 | 동일 검수자가 두 결과를 검토한 기록 | 추가 검토 시간·오탐 부담이 이득보다 큰지 |
| 비용 | 시도별 usage·누락 여부·단가 확인일 | 실패·재시도 누락, Batch 할인 오적용, 청구액 단정 |

웹은 8조 단위 즉시 Messages API를 2회 호출한다. 공급자 Batch API 할인은 적용하지 않는다. 웹 토큰 추정 단가는 [공식 Sonnet 5.5 문서](https://platform.claude.com/docs/en/models/sonnet-5-5/overview)와 [공식 캐시 문서](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)를 2026-10-22 확인했다: 백만 토큰당 입력 $2, 출력 $10, 5분 캐시 생성 $2.50, 캐시 읽기 $0.10. 모델은 교체하지 않았다.

`work_rules_precise_runs.usd`는 기존 스키마를 유지하는 토큰 기반 추정치이며 실제 청구액이 아니다. 서버 구조화 로그의 `estimatedUsd`, `billingVerified:false`, `usageComplete`, `accounting`을 함께 확인한다. usage가 없는 실패·취소는 정확한 비용을 알 수 없고 추정 합계가 실제 비용보다 작을 수 있다. 실패 실행도 본문 없는 구조화 로그를 남기며, 운영 청구 대조는 미실시다. DB migration이나 운영 설정을 변경하지 않았다.

법령명·조문 식별자 일치는 원문 연결만 의미한다. 법률 적용·인용 문장의 의미·원문 최신성 검증을 대신하지 않는다. 원문 미연결 항목은 추가 확인으로 남기며, AI 인용은 연결 여부와 관계없이 미검증 표시한다.
