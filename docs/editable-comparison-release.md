# 취업규칙 신구대조표 출고 검증

공식 공개 출처: https://www.alio.go.kr/download/rulefiledown.json?fileNo=194023 (한국중부발전, 2024-01-29 취업규칙).
부모 환경에서 확인한 원본 PDF SHA256: 54a1ff52274c7252d5ccf403ebbbd65464eceda33d909d118a5a78a7a74bc570. 이 실행 환경은 원본 PDF bytes 전송이 proxy 403으로 실패하여 해당 해시를 독립 검증하지 못했다.
18쪽 content-read에서 머리말/쪽번호만 정리한 파생 텍스트 SHA256: 22bf3a30e0e546c41f912be8ad8929e1dace4206ac1e5bf7dc3479231bce6a53.

공개 코드: https://github.com/seojaehong/labor-law-guide/tree/fix/editable-comparison-exports

Word의 반복 표 머리글, 본문 크기, 여백, 고정 열 너비와 긴 행 분할을 개선했다. Excel은 줄바꿈, 머리글/첫 열 고정, 인쇄 설정, 긴 셀 계속행, 숨김 원문보관을 제공한다. 생성 중 본문/검사기간이 바뀌면 오래된 다운로드를 취소한다. Excel 셀 한도를 넘으면 원문을 자르지 않고 오류로 중단한다.

법령 인용 줄바꿈을 가짜 조문으로 분리하던 오류를 수정했다. 가족돌봄 규칙 43번에 명시적 제도 anchor를 추가하여 원문 제29조 제1항 제11호의 조부모·손자녀 범위를 찾는다. 제50조 제1항 제13호의 간호휴직은 독립 관련 근거로 남으며 다른 법적 요건의 충족을 보증하지 않는다. 넓은 단어만으로 무관한 조문을 통과시키지 않는다.

파생 텍스트 붙여넣기와 파생 DOCX 실제 파일 입력, 정정, Word/Excel 다운로드를 1280px/390px에서 검증했다. 관찰 저장은 mock API만 사용했다. 현재 UI는 PDF 입력을 지원하지 않으며 원본 PDF UI E2E는 수행하지 않았다.

python-docx/openpyxl로 장문 편집 후 LibreOffice 26.8 alpha로 PDF 렌더를 검사했다. 실제 MS Word/Excel/한글에서의 편집 결과는 미검증이다. 최신 법령·별도 규정·단체협약·기관 적용범위 전수 법률 검증은 미완료이며 키워드 판정은 법적 적합성 보증이 아니다.

이 출고에는 E01 상담·서면 코드, 유료 모델, 공유예산, 인증, DB migration, 자격증명 변경이 포함되지 않는다. 기존 E01 PR은 별도 검토 상태로 유지한다.

후속 인쇄 회귀: 계속행 표시용 시트의 자동 필터를 제거했다. 행별 정렬/필터는 조문을 분리하므로 사용하지 말라는 안내를 추가했다. 문자 수와 예상 시각 줄 수(최대18줄)를 함께 제한하고 LF/CRLF 원문을 정확히 보존한다. 숨김 원문보관은 내보내기 당시 원본이며 편집 후 자동 갱신되지 않는다. 합성101줄 사례의 마지막 문장을 LibreOffice PDF 렌더에서 확인했다. 실제 MS Office 검수와는 구분한다.
