## 워드마크·요약·대비 후속 보완

- 기존 4.7% 폭 조정만으로 타이포 인상이 충분히 달라지지 않았다는 검토를 반영했습니다. 새 SVG는 생성형 이미지 없이 한글 부품 경로를 직접 구성했고, 내부 여백·사선으로 잘린 획 끝·세로/가로 획 대비를 반복합니다. 원안과 새 안의 390px 헤더·320px 공유 카드 픽셀 비교를 제공합니다.
- 일반 OG는 큰 워드마크와 짧은 역할 설명을 중심으로 하며, 중앙에 브랜드 이름을 고딕으로 중복하지 않습니다. 글·법령 OG는 실제 콘텐츠 제목을 중심으로 합니다.
- 글 목록의 HTML 요약·부제는 기존 shareText로 처리해 텍스트로 표시합니다. DB·원문 객체와 법률 본문을 바꾸지 않으며 원문 보존 회귀 검사를 추가했습니다. 27개 파일 252개 테스트 통과, 최종 production fixture 빌드 102개 정적 페이지 및 순차 TypeScript 검사를 수행했습니다.
- FAQ의 기존 ‘노동조합’ 이름을 인코딩한 상세 경로를 확인했습니다. 합성 데이터가 없는 빈 결과 화면이며 실제 질문·분류 정확성을 검증했다는 뜻은 아닙니다.
