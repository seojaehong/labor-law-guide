작성일: 2026-10-05. 디자인 구현·레이아웃 검사 기록이며 법률 내용의 검수일이 아닙니다.

## 구현
- 승인 메뉴: 일의 이야기 / 달라지는 일 / 내 일 점검 / 근거 찾기. 소개·상담은 보조 링크.
- 헤더 SVG 워드마크의 글자 폭·간격 조정, 라이트·다크 파일 및 비교 화면.
- 공통 종이·먹·청록 강조색, 실제로 제공되는 한국어 로컬 폰트, 본문 행간·모바일 메뉴·44px 조작 영역.
- 공통 OG 이미지 렌더러 및 일반/글/법령 공유 이미지. 제목·설명 정리, 관리자 공유 이미지는 일반 브랜드 이미지. 기존 robots/noindex 정책 보존.
- /laws 목록·상세·달력 및 취업규칙 점검창의 스타일, 점검창 포커스 제한·Escape 닫기·복원, 상세 query 링크의 초기 상태 복원.
- 독립 퇴직금 HTML의 스타일·탐색·공유 이미지 연결. 계산 스크립트는 보존.

## 실제 검사
- TypeScript 검사 통과. 읽기 전용 합성 자료 서버를 사용한 production build 통과(101개 정적 페이지 생성).
- 단위 테스트 27개 파일, 248개 검사 통과. 퇴직금 날짜 검사는 Windows 명령 길이 한도를 피하도록 stdin으로 실행하며 계산 결과·날짜 경계 검증은 유지.
- 주요 변경 TS/TSX eslint: 오류 없음.
- /laws 360/390/430/768/1024/1440px: 문서 가로 넘침 없음, 로컬 한국어 폰트 로드 확인.
- /laws 상세 펼침 → 점검창 → Escape 닫기 → 상세 링크 새로고침 복원 확인.
- 일반·법령 OG HTTP 200, 1200×630 PNG. 한글·SVG 워드마크 표시 확인.
- 공개 주요 12개 경로(홈, 글 목록·본문, 판정·판례·행정해석 본문, 도구, 상담, 독립 퇴직금)는 합성 자료 서버에서 HTTP 200 및 390/1280px 가로 넘침 없음.
- 보조 15개 경로는 합성 자료 서버에서 390px 가로 넘침 없음. /guide 첫 이동의 ERR_ABORTED는 production 미리보기에서 재확인했고 HTTP 200 및 가로 넘침 없음. 글 분류·뉴스레터 안내 3개·검색 리다이렉트 2개도 재확인. 점검창의 예시 입력·내부 포커스 확인.

## 검증의 한계
로컬 환경 파일은 실 DB 주소가 아닌 빌드용 주소였습니다. 글·판례의 운영 데이터 검증 완료로 해석하지 않습니다. 저장소가 제공하는 읽기 전용 합성 자료 서버를 사용했습니다. 법령 원문·날짜·취업규칙 제안 문안의 정확성을 새로 확정하지 않았으며 검수 전 표시를 유지했습니다. AI·사진 판독·상담·뉴스레터 제출 및 실제 캘린더 구독·알림은 호출하지 않았습니다.
