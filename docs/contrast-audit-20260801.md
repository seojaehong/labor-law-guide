# 명도대비 측정 보고 (DESIGN.md §7.3 / §9 P6-4)

측정일 2026-08-01 · 대상 `src/app/globals.css`의 `:root`·`.dark` 토큰 · 기준 WCAG 2.1 AA(본문 4.5:1)

측정 방법: 토큰의 `var()` 체인을 hex까지 해석한 뒤 상대휘도로 대비를 계산했다.
**틴트 배경은 알파를 페이지 바탕에 합성한 실제 색으로 비교했다** — `rgba(…, 0.12)`를 원색 그대로
비교하면 다크 배지가 전부 미달로 나오는 오판이 생긴다(1차 측정에서 실제로 그랬다).

### 다크 솔리드 — 판정 보류 (측정 가정이 불확실)

다크의 `--color-accent`(3.71) · `--color-accent-ink`(3.07) · `danger`(2.77) · `success`(1.92) ·
`warn`(1.67)은 **흰 잉크를 가정한 수치**다. 다크에서 이 토큰들은 밝은 색이므로 실제로는
어두운 잉크를 얹을 가능성이 높고, 그렇다면 이 수치는 의미가 없다.

DESIGN.md §3.3이 다크 accent 3.07을 미달로 명시한 것과는 일치하지만, `danger`·`success`·
`warn`까지 흰 잉크로 쓰는지는 문서가 규정하지 않았다. **어떤 잉크를 얹는지 정한 뒤 재측정해야
한다** — 지금 값을 바꾸면 근거 없이 팔레트를 흔드는 것이 된다.
