## 상태어 (G2)

| 상태 | 무엇과 무엇을 비교한 결과인가 | 이것이 아니다 |
|---|---|---|
| `confirmed` 「주소로 찾은 지사」 | 주소의 시도·시군구·동을 공단 공개 관할 문구와 맞춰 그 공단에서 지사 한 곳만 남음 | 공단이 배정한 관리지사(고지서·EDI)와 같다는 뜻이 아니다 |
| `candidates` 「후보 N곳」 | 둘 이상이 맞거나, 동을 몰라 분할 관할을 못 가르거나, 관할 문구가 「…에 한함」「…제외」로 일부만 덮음 | 하나를 추정해 고르지 않는다 |
| `none` | 시도를 못 읽었거나 어떤 지사 문구에도 안 맞음 | 「관할 지사가 없다」가 아니다 |
| 행 강조 `hit` | 지사 담당자 표의 담당업무 원문에 이 주소의 동·읍·면 이름이 글자로 들어 있음 | 사업장명 자음 범위(「[국~넝]」)·「오창읍 ㅈ-ㅎ」은 아직 안 본다(후속) |
