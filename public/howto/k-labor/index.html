03 · 설치

명령 한 줄이면 등록됩니다

설치 파일을 따로 받지 않습니다. AI가 도구를 부를 때 npm에서 k-labor를 받아 내 PC에서 실행합니다.

  1. Node.js 20 이상 확인

    명령 창에서 아래를 실행해 v20 이상이 나오면 됩니다. 없으면 nodejs.org에서 LTS 판을 설치합니다.

    node -v

  2. AI에 등록

    Claude Code는 명령 한 줄입니다. 묶음을 고르려면 맨 위 묶음 고르기에서 만든 명령을 씁니다.

    claude mcp add --scope user k-labor "--" npx -y k-labor mcp

    Claude Desktop은 설정 파일 claude_desktop_config.json에 넣습니다.

    {
  "mcpServers": {
    "k-labor": { "command": "npx", "args": ["-y", "k-labor", "mcp"] }
  }
}

    Cursor·Windsurf 등도 같은 command·args를 그 프로그램의 MCP 설정에 넣습니다.

  3. 다시 열고 말 걸기

    Claude Desktop은 껐다 켜고, Claude Code는 새 대화를 엽니다. 「k-labor 도구 목록 보여 줘」라고 하면 켜진 도구가 나옵니다.

설치 없이 — 원격 주소

claude.ai에서 설정 → 커넥터 → 커스텀 커넥터 추가를 누르고 아래 주소를 넣습니다. 도구 26개가 붙습니다.

https://yellowenvelope.kr/api/mcp/mcp

Windows에서 Claude Desktop이 npx를 못 찾으면

cmd /c로 감쌉니다.

{
  "mcpServers": {
    "k-labor": { "command": "cmd", "args": ["/c", "npx", "-y", "k-labor", "mcp"] }
  }
}

05 · 팩스·문자와 법제처

보내는 도구는 내 계정 값을 넣어야 켜집니다

이 패키지에는 기본 계정도 기본 발신번호도 없습니다. 값이 빠지면 무엇이 빠졌는지 알려 주고 아무것도 보내지 않습니다.

이름뜻
POPBILL_LINK_ID팝빌 연동 링크아이디
POPBILL_SECRET_KEY팝빌 연동 비밀키
POPBILL_CORP_NUM팝빌에 가입한 사업자등록번호(숫자 10자리)
POPBILL_FAX_SENDER팝빌에 등록한 팩스 발신번호
POPBILL_SMS_SENDER팝빌에 등록한 문자 발신번호
POPBILL_IS_TEST기본은 테스트환경. 실제로 보내려면 false
LAW_OC법제처 국가법령정보 Open API 이용자 ID. 없으면 묶어 둔 자료로만 답합니다

넣는 곳

Claude Desktop은 설정 파일의 "env" 칸에, Claude Code는 등록할 때 -e 이름=값으로 넣습니다.

claude mcp add --scope user k-labor -e LAW_OC=내OC "--" npx -y k-labor mcp --groups work-rules

내OC를 법제처에서 받은 ID로 바꿉니다. "--"의 따옴표는 PowerShell에서 --가 빠지지 않게 하려는 것으로, 다른 명령 창에서도 그대로 써도 됩니다.

법제처 조회가 막힐 때

법제처는 OC를 신청할 때 등록한 IP·도메인이 아니면 「사용자 정보 검증에 실패하였습니다」로 거절합니다. 해외 IP도 막습니다.

06 · 개인정보

주민등록번호는 AI 대화에 실리지 않습니다

계산·계약 도구는 주민등록번호를 받지 않습니다. 신고서처럼 꼭 필요한 곳은 명단을 파일 경로로만 받아 도구가 직접 읽습니다.

내 PC에 설치했을 때

명단·서류

신고서 명단 파일(peopleFile)신고서 PDF취업규칙 본문·파일계약서 파일

설치판에서 밖으로 나가는 것은 세 가지뿐

  1. 사업자등록번호로 관할 지사를 찾을 때 그 번호만 일의 무늬로 보냅니다. 주소로 찾으면 아무것도 나가지 않습니다.
  2. 팩스·문자는 본인 팝빌 계정으로 보냅니다.
  3. 법제처에는 법령명·날짜·판 번호만 묻습니다.

원격 주소로 쓸 때

도구에 넣는 값이 일의 무늬 서버로 전송돼 계산됩니다. 주민등록번호를 받는 도구는 원격 주소에 없습니다.

✕ 일의 무늬는 입력값을 저장하거나 모으지 않습니다

응답에서도 가립니다

도구 응답에 주민등록번호 모양이 섞이면 나가기 전에 가립니다. 근로계약서 점검은 입력에 주민등록번호 모양이 있으면 점검하지 않습니다.

보내기 전에 미리보기

팩스·문자는 AI가 보내기 표시(confirm: true)를 넣어 부른 호출에서만 실제로 나가고, 그 전에는 미리보기만 돌려줍니다. 이 표시는 AI가 넣는 값이니 AI 앱의 도구 승인 창을 켜 두고 미리보기를 읽은 뒤 승인하세요. 문자 본문에 주민등록번호 모양이 있으면 보내지 않습니다.

07 · 문제 해결

안 될 때 먼저 볼 것

Claude Desktop에 도구가 안 보여요

설정 파일을 고친 뒤 Claude Desktop을 완전히 껐다 켜야 합니다. Windows에서 npx를 못 찾는 경우가 많으니 위의 cmd /c 설정으로 바꿔 보세요.

서버가 뜨지 않고 묶음 목록만 나와요

없는 묶음 이름을 넣은 경우입니다. 묶음 이름은 nhis·popbill·contract·calc·leave·tax·duties·work-rules·nosa·forms·docs·law입니다. fax·sms는 popbill로 받습니다.

npx -y k-labor --help
Node 버전 오류가 나요

node -v가 v20보다 낮으면 nodejs.org에서 LTS 판으로 올립니다.

원격 주소에 없는 도구가 있어요

정상입니다. 원격 주소에는 계산·점검 도구 26개만 있습니다. 건강보험 신고(관할 지사 찾기 포함)·팩스·문자·취업규칙·법령·한글 문서·법령·판례 조회 묶음 전체, 근로계약서 파일 저장, 노사협의회 서류·기록, 모성보호 서식 칸 검사·파일은 내 PC 설치판에만 있습니다. 이것들이 필요하면 내 PC에 설치하세요.

팩스가 안 나가요

응답에 빠진 값이 적혀 있습니다. 발신번호가 팝빌에 등록돼 있는지, POPBILL_IS_TEST가 기본값(테스트환경)으로 남아 있지 않은지 확인하세요.

08 · 자주 묻는 질문

묻는 질문

돈이 드나요?

도구는 무료이고 소스 코드도 MIT 라이선스로 공개돼 있습니다. 팩스·문자는 본인 팝빌 요금이 듭니다.

사이트 계산기와 결과가 같나요?

같은 엔진을 묶었습니다. 같은 입력이면 사이트 화면과 같은 값이 나옵니다.

어떤 AI에서 되나요?

MCP를 지원하는 도구에서 됩니다. Claude Code, Claude Desktop, claude.ai 커스텀 커넥터, Cursor, Windsurf 등입니다.

결과를 그대로 써도 되나요?

계산과 대조의 1차 결과입니다. 취업규칙 대조는 낱말을 맞춰 본 것이고, 바꿀 문안은 법이 정한 최저 기준이라 회사 사정에 맞게 확인한 뒤 씁니다.

09 · 하지 않는 일

이 도구가 하지 않는 일

  • 4대보험·취업규칙 신고를 접수하지 않습니다. 서류를 만들고 날인이 필요한 곳을 알려 주는 데까지입니다
  • 받을 팩스 번호를 정해 두지 않습니다. 관할 지사 찾기로 나온 번호를 사람이 확인해 넣도록 안내합니다
  • 일의 무늬는 입력값을 저장하거나 모으지 않습니다
  • 기본 팝빌 계정·기본 발신번호를 넣어 두지 않습니다
  • 서명·날인 칸을 채우지 않습니다

일의 무늬가 만든 업무 도구

  • 공단 로그인공단 사이트 네 곳에 키 하나로 로그인하는 윈도우 프로그램
  • 노동 업무 도구 (k-labor)계산·근로계약서·신고서·취업규칙 점검을 AI 대화창에서
  • 공단 업무 도구 모음관할 지사 찾기·신고서 만들기 등 웹에서 바로 쓰는 도구
