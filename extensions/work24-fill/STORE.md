# 크롬 웹스토어 등록 자료 — 일의 무늬 — 고용24 확인서 채우기

묶음: `node scripts/pack-work24-fill.mjs` → `artifacts/work24-fill-<버전>.zip`(개발용 localhost 주소를 뺀다)

## 등록 정보

- 이름: 일의 무늬 — 고용24 확인서 채우기
- 범주: 생산성(업무)
- 언어: 한국어
- 홈페이지: https://yellowenvelope.kr/tools/childcare-reduction
- 개인정보처리방침: https://yellowenvelope.kr/privacy#extension
- 지원 연락처: 사이트 개인정보처리방침의 보호책임자 이메일

### 짧은 설명(132자 이내)

일의 무늬 육아기 근로시간 단축 계산 화면에서 보낸 값을 고용24 「육아기 근로시간 단축 확인서」 칸에 넣습니다. 저장·신청은 직접 누릅니다.

### 자세한 설명

사업주가 고용24에서 「육아기 근로시간 단축 확인서」를 쓸 때, 단축 기간·단축 전후 주 소정근로시간·통상임금·월 소정근로시간을 손으로 옮겨 적는 일을 줄입니다.

1. 일의 무늬(yellowenvelope.kr) 육아기 근로시간 단축 계산 화면에서 값을 넣고 「확장으로 보내기」를 누릅니다.
2. 고용24에 본인 인증서로 로그인해 육아기 근로시간 단축 확인서 화면을 엽니다.
3. 화면 오른쪽 아래에 넣을 값이 보입니다. 「칸에 넣기」를 누르면 해당 칸에 들어갑니다.
4. 화면을 확인한 뒤 근로자 정보 입력·저장·신청은 직접 합니다.

- 받은 값은 브라우저를 닫으면 사라지는 확장 저장소에 최대 30분 두고, 고용24 화면이 한 번 가져가면 지웁니다.
- 값을 서버나 다른 곳으로 보내지 않습니다. 네트워크 권한이 없습니다.
- 주민등록번호·비밀번호·첨부 칸은 읽거나 채우지 않습니다. 저장·신청 버튼은 누르지 않습니다.
- 고용24 화면이 바뀌면 칸을 찾지 못했다고 알리고 멈춥니다.

## 심사 항목

- 단일 목적: 일의 무늬 계산 화면의 값을 고용24 육아기 근로시간 단축 확인서 칸에 옮겨 넣는다.
- 권한 `storage`: 계산 화면에서 받은 값을 고용24 화면이 열릴 때까지(최대 30분) `chrome.storage.session` 에 둔다.
- 호스트(콘텐츠 스크립트): `yellowenvelope.kr/tools/childcare-reduction*`(값 받기), `www.work24.go.kr/ei/b/b/1500/openHPEIBB1500M06.do*`(값 넣기)만.
- 원격 코드: 쓰지 않는다(모든 코드가 묶음 안에 있다).
- 데이터 사용 공개: 「재무·결제 정보」 아님. 「개인 활동」 아님. 이용자가 입력한 근로조건 값(임금 금액 포함)을 기기 안에서만 다룬다 → 「웹사이트 콘텐츠」 항목에 해당 여부를 표시하고, 판매·제3자 전달·신용평가 목적 사용 없음에 체크.
