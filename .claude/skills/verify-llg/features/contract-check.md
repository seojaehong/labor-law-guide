# 근로계약서 점검

근로계약서 내용을 4단계(기본 → 근로시간 → 임금·지급 → 문제조항)로 입력하면 25개 법정 항목을 브라우저에서 점검해, 항목마다 「위반 / 리스크 / 적정 / 자료 필요」와 근거 조문·수정 방향을 보여준다. 이 지도는 그중 최저임금 충족(MINWAGE)의 세 분기 — 월급제(법리 C), 시급제(법리 A), 주휴 포함 시급(법리 B) — 를 화면으로 돈다. 폼 입력과 판정은 브라우저 안에서만 돈다. 사진 자동 입력은 서버를 거치지만 이 지도는 사진 경로를 쓰지 않는다.

## Sub-features

- `cc-monthly` ① 월급제 · 기본급 2,156,880 · 주 5일 09:00~18:00 · 휴게 60분 = 「적정」, 「월 산입 임금 2,156,880(기본급) ÷ 최저임금 적용기준 월 209H = 시간당 10,320 ≥ 2026년 최저시급 10,320」. 출처 `tests/unit/contract-check-part-time-law.test.ts` 「C 월급제 › 주 40H → 209H」.
- `cc-hourly-under` ② 시급제 · 시급 9,000 · 같은 근무시간 = 「위반」, 「계약 시급 9,000 (시급제·산출근거 시간 없음 — 기본급을 시급으로 봄) < 2026년 최저시급 10,320 (시간당 1,320원 미달)」. 출처 법리 A(계약 시급으로만 비교) · `contract-check-review3.test.ts` 「시급제 + 시급만(시간 비움) → 시급 그대로 A」.
- `cc-hourly-incl` ③ 시급제 · 시급 10,320 · 주휴 「포함」 = 「위반」, 「주휴 포함 시급 10,320 (…) < 기준액 = 최저시급 10,320 × (소정 40H+주휴 8H)/40H = 12,384 (최저임금법 시행령 §5①2호)」, 수정 방향 「… = 12,384원 이상으로 인상」. 출처 `contract-check-part-time-law.test.ts` 「B › 주 40H·5일: 10,320 × 48/40 = 12,384 — 12,383 위반」.
- `cc-screens` 입력 1~4단계 화면(①에서)과 결과 화면 셋의 금지어 0 · 가로 넘침 없음.

## How to get to it (user POV)

- `/tools` 목록 「근로계약서 점검」, 또는 `/tools/contract-check`. 「다음」을 세 번 누르고 4단계에서 「결과 보기」를 누르면 「점검 결과」가 나온다.

## Driving it with verify.mts

Preconditions:

- doctor OK. 첫 화면 = 모든 칸 비어 있음, 선택지는 전부 「모름·건너뛰기」.
- 「계약 시작일」 2026-03-02 를 넣는다. 비우면 최저임금 연도를 정하지 못해 「자료 필요」(기본급 또는 계약 시작일 미기재)가 나온다.
- 결과는 `#cc-print-area` 의 항목 `li` 를 규칙 이름 「최저임금 충족」으로 잡는다. 항목 글자 = 상태 배지 · 규칙 이름 · 근거 조문 · 설명 · 수정 방향.
- 시나리오마다 페이지를 새로 연다(`waitUntil: 'load'` 뒤 하이드레이션 대기 — Gotchas).

- **① 월급제.** 「계약 시작일」 `2026-03-02`, 「월급제」 버튼, 「기본급」 `2156880` → 다음 → 「주 근무일수」 `5`, 「출근 시각」 `09:00`, 「퇴근 시각」 `18:00`, 「하루 휴게시간」 `60` → 다음 → 다음 → 결과 보기. 「적정 최저임금 충족 … 월 209H = 시간당 10,320 ≥ 2026년 최저시급 10,320」. 1~4단계와 결과 화면마다 금지어·넘침을 본다.
- **② 시급제 9,000.** 새로 열어 같은 순서로, 「월급제」 대신 「시급제」 버튼 → 「시급」 `9000`. 「위반 최저임금 충족 … 계약 시급 9,000 (…) < 2026년 최저시급 10,320 (시간당 1,320원 미달)」.
- **③ 주휴 포함.** 새로 열어 「시급제」 → 「시급」 `10320` → 「포함」 버튼. 「위반 최저임금 충족 … 주휴 포함 시급 10,320 (…) < 기준액 = 최저시급 10,320 × (소정 40H+주휴 8H)/40H = 12,384 (최저임금법 시행령 §5①2호)」와 수정 방향 「12,384원 이상」.

## Gotchas

- 헤드리스에서는 `networkidle` 에 닿지 않는다(261102 실측 90초). 사진 업로드 카드의 Cloudflare Turnstile 이 챌린지를 계속 돌린다. 그래서 `waitUntil: 'load'` 로 열고, 입력칸에 React 이벤트(`__reactProps$…`)가 붙은 뒤 채운다 — load 직후 채우면 하이드레이션이 값을 되돌릴 수 있다.
- Turnstile iframe(`challenges.cloudflare.com`)은 자기 CSP 위반(`Connecting to 'data:,' violates … connect-src`)과 개발자도구 감지 로그(`%c%d font-size:0;color:transparent`)를 console.error 로 낸다. 사이트 응답에는 CSP 헤더가 없다(261102 실측) — 우리 페이지 오류가 아니므로 `report.json` 의 `thirdPartyConsole` 에만 남기고 판정에서 뺀다. 나오는 run 과 안 나오는 run 이 있다.
- 이 PC 에서는 `brunhild.challenges.cloudflare.com` 이름 풀이가 안 된다(nslookup 실패). 운영 결함이 아니라 이 환경 사정이다.
- 선택지(계약기간·급여 형태·주휴 포함 등)는 radio 가 아니라 `button` 이다. 「포함」은 「별도·미포함」과 부분일치하므로 `exact: true` 로 누른다. 1단계에는 「모름·건너뛰기」가 4개라 누르지 않는다.
- 「시급」 칸과 「시급에 주휴수당이 포함돼 있다고 적혀 있나요?」 선택은 「시급제」를 누른 뒤에만 나온다. 월급제·모름이면 같은 자리에 「기본급」 칸이 있다.
- 「다시 입력하기」는 결과와 단계만 되돌리고 입력값은 그대로 둔다. 이어서 돌리면 앞 시나리오의 「포함」이 남을 수 있어 시나리오마다 새로 연다.
- 시급제에서 산출시간을 비우면 시급 뒤에 「(시급제·산출근거 시간 없음 — 기본급을 시급으로 봄)」이 붙는다. 「시급」 칸 값이 엔진에는 BASE(기본급) 항목으로 가기 때문이다(`formState.ts` `buildContract`).
- 결과 칩(위반 N 등)은 다른 24개 항목에 따라 흔들려 걸지 않는다. ③ 실측은 위반 2 · 리스크 0 · 적정 18 · 자료 필요 4(위반 = 최저임금 충족 + 필수 명시사항(전 근로자)).
- 최저시급은 계약 시작일의 연도로 고른다. 시작일을 2027년으로 바꾸면 기대값이 바뀐다.
