# 3.3% 계약 점검

프리랜서(사업소득 3.3%)로 계약한 사람이 실제로 일한 모습을 질문 8개로 답하면, 대법원 2006. 12. 7. 선고 2004다29736 판결의 근로자성 요소와 항목마다 대조해 「근로자로 볼 요소가 있습니다 / 적습니다」를 보여준다. 고정급·근로소득세·4대보험·취업규칙(가벼운 항목)은 근로자가 아닌 쪽으로 답해도 「적습니다」로 쓰지 않고 「회사가 정할 수 있는 사정이라 이것만으로 근로자가 아니라고 쉽게 볼 수 없다는 것이 판례입니다」를 낸다. 점수·개수·결론은 내지 않는다. 아래에서는 같은 월 보수를 3.3%로 뗄 때와 근로소득(실수령액 계산기와 같은 계산)으로 뗄 때의 예상 실수령을 나란히 보여준다.

## Sub-features

- `cc-empty` 답 없음 = 모든 항목 「확인이 필요합니다」.
- `cc-p3` 2004다29736 사실관계형(Q1·Q2 예, Q3·Q4 아니요, Q5 시간·일수, Q6~Q8 아니요) = Q1~Q5 「있습니다」, Q6~Q8 가벼운 항목 문장, 카드에 「적습니다」 없음.
- `cc-p2` 독립 쪽 전부 = Q1~Q5 「적습니다」, Q6~Q8 은 여전히 가벼운 항목 문장.
- `cc-m1` 300만 = 3.3% 2,901,000원 · 근로소득 2,626,700원.
- `cc-m2` 2,345,678 = 2,268,278원 · 2,084,308원(10원 미만 버림).
- `cc-m3` 300만·식대 20만 = 2,901,000원(3.3%는 식대까지 전액) · 2,665,440원.
- `cc-m7` 1,200만 = 3.3% 11,604,000원 · 근로소득은 소득세를 계산하지 않고 4대보험 909,100원만.
- `cc-small` 3만원 = 3.3% 29,010원 · 근로소득 쪽은 계산하지 않음(4대보험 하한 때문에 공제가 보수보다 많다).
- `cc-s1` 33,000 = 3.3% 31,920원(990원도 뗀다 — 시행령 제149조의3).

## How to get to it (user POV)

- `/tools` 목록 「3.3% 계약 점검」, 또는 `/tools/contractor-check`.

## Driving it with verify.mts

Preconditions:

- doctor OK. 기본 입력 = 질문 답 없음, 월 보수 3,000,000원, 식대 없음, 가족 1명.
- 근로소득 쪽 요율은 오늘 날짜(KST)로 `rates.ts` 에서 고른다. 아래 기대값은 2026년 요율이다.
- 점검 카드는 `[data-part="check"] section[aria-live]`, 금액 카드는 `[data-part="money"] section[aria-live]` 로 읽는다.

- **첫 화면.** 점검 카드 「확인이 필요합니다」. 금액 카드 「3.3%로 떼면 2,901,000원, 근로소득으로 떼면 2,626,700원」.
- **P3.** 질문 묶음(fieldset legend)마다 고른다 — 「회사가 업무 내용을…」 예, 「회사가 근무시간과…」 예, 「일에 쓰는 비품…」 아니요, 「다른 사람을 써서…」 아니요, 「보수가 일한 시간…」 예, 「기본급이나 고정급…」 아니요, 「보수에서 근로소득세를…」 아니요, 「회사 취업규칙…」 아니요. 카드에 「근로자로 볼 요소가 있습니다」와 「쉽게 볼 수 없다는 것이 판례입니다」가 있고 「적습니다」가 없다.
- **P2.** 위에서 앞 다섯 개를 반대로 고른다(아니요·아니요·예·예·아니요). 「요소가 적습니다」와 가벼운 항목 문장이 있고 「요소가 있습니다」가 없다.
- **M2.** 「월 보수」 `2345678`. 2,268,278원 · 2,084,308원.
- **M3.** 「월 보수」 `3000000`, 「그중 식대」 `200000`. 2,901,000원 · 2,665,440원.
- **M7.** 식대 비움, 「월 보수」 `12000000`. 11,604,000원, 「소득세를 계산하지 않고」, 909,100원.
- **소액.** 「월 보수」 `30000`. 29,010원, 「근로소득 쪽은 계산하지 않았습니다」.
- **S1.** 「월 보수」 `33000`. 「3.3%로 떼면 31,920원」.

## Gotchas

- 2027. 1. 1. 부터 국민연금 근로자 몫이 1만분의 500 이라 근로소득 쪽 기대값이 바뀐다(300만 = 2,619,200원). 3.3% 쪽은 그대로다. 2027. 7. 1. 부터는 국민연금 기준소득월액 상·하한 고시가 아직 없어 근로소득 쪽이 「보험료율·기준이 아직 반영되지 않아 계산하지 않았습니다」가 된다 — 3.3% 쪽은 계속 나온다.
- 가벼운 항목 문장 안에는 「적습니다」가 없다. 점검 카드 밖의 안내 문단도 「적습니다」를 쓰지 않게 했다(카드만 읽지만 혹시 선택자를 넓힐 때를 위해).
- 질문 보기 글자는 「예, 본인이 갖춘다」처럼 꼬리가 붙어 있어 `/^예/`·`/^아니요/` 로 고른다. 묶음은 `getByRole('group', { name: /^질문 앞 글자/ })`.
- 결과 화면에 연락 유도가 없어야 한다(세액 계산 도구 공통 장치 261028). 「세무대리·신고서 작성 대행이 아닙니다」 안내와 홈택스 링크는 금액 카드 아래 문단에 있다.
