# 4대보험 관할 지사·담당자 번호 찾기

사업장 주소(또는 사업자등록번호 → 근복 공개 사업장 주소)로 근로복지공단·국민건강보험공단·국민연금공단의 관할 지사와 업무별 담당 전화·팩스를 보여준다. 지사 자료는 `data/branch-directory/*.json`(각 공단 지사찾기 원문, 수집일은 파일 안 `collectedAt`).

## Sub-features

- `bd-confirmed` 주소의 동까지 맞으면 공단마다 지사 한 곳(「주소로 찾은 지사」).
- `bd-candidates` 동을 모르거나 부분 관할이면 「후보 N곳」으로 내고 고르지 않는다.
- `bd-hit` 지사 안 담당업무 문구에 이 주소의 동·읍·면이 적힌 행을 맨 앞에 강조(`tr[data-hit="1"]`).
- `bd-biz` 사업자등록번호 입력 → 근복 공공 API 주소 → 같은 결과(지점이 여럿이면 고르기). 운영 키가 있어야 돈다.

## How to get to it (user POV)

- `/tools` 목록에서 「4대보험 관할 지사·담당자 번호 찾기」.
- 주소 `/tools/branch-directory` 직접.

## Driving it with verify.mts

Preconditions: doctor OK.

- `drive --feature branch-directory`.
  - 청주 상당구 서문동 → 안내문(「관리지사를 먼저 확인」) · 근복 청주지사 확정 · 강조 행 `043-229-5128` · 건보 청주동부지사 · 연금 동청주지사.
  - 영등포구 여의공원로 101(동 없음) → 건보 「후보 2곳」 영등포남부·영등포북부.

## Gotchas

- 표 안 부서·담당업무·관할 문구는 공단 원문 인용이라 「상담」「체불」「판정」 같은 말이 들어 있다. 그 영역은 `data-official` 로 표시했고 verify.mts 금지어 검사에서 뺀다. 우리 문장(copy.ts)은 단위 시험이 금지어를 따로 본다.
- 관할 매칭은 공단 공개 문구를 읽은 것이다. 공단이 소재지와 다른 지사를 관리지사로 정한 사업장이 있어 결과 상단에 「고지서·EDI 관리지사 우선」 안내를 늘 낸다.
- 주소 조회도 `branch-dir:` 키로 IP당 하루 300회, 사업자번호 조회는 `workplace:` 키(60회)를 /api/tools/workplace 와 같이 쓴다.
