# 최저임금 확인 계산기

월급·주급·일급·시급을 시행령 §5① 대로 시간급으로 바꿔 올해와 내년 최저임금(2026 10,320원 · 2027 10,700원)과 비교한다. 매달 주는 정기상여금·현금 식비를 더하고, 수습 90% 조건을 고를 수 있다.

## Sub-features

- `mw-month` 월급(주 40시간 = 209시간) 비교, 올해·내년 두 줄.
- `mw-boundary` 1원 모자람.
- `mw-probation` 수습 90%(1년 이상 계약 + 3개월 이내).
- `mw-simple` 단순노무 종사자는 감액 없음.

## How to get to it (user POV)

- `/tools` 목록 「최저임금 확인 계산기」, 또는 `/tools/min-wage`.

## Driving it with verify.mts

Preconditions:

- doctor OK. 기본 입력 = 월급 2,156,880원, 주 40시간.

- **기본.** 답 카드에 「2026년 최저임금(시간당 10,320원) 이상」과 「79,420원 적습니다」(2027).
- **1원.** 첫 금액 칸에 `2156879`. 「한 달 1원 적습니다」.
- **수습.** 단위 「시급」, 금액 `9288`, 「수습 중이라면」 펼침 → 「수습 기간이다」·「1년 이상」·「3개월이 지나지 않았다」 체크. 「수습 기준(최저임금 10,320원의 90%, 시간당 9,288원) 이상」.
- **단순노무.** 「단순노무 종사자다」 추가 체크. 「2026년 최저임금(시간당 10,320원)보다 1시간 1,032원 적습니다」.

## Gotchas

- 「올해·내년」은 오늘 날짜와 `rates.ts` 에서 고른다. 2027년이 되면 줄이 하나(2027)로 줄고 2028 고시가 없으면 내년 줄이 사라진다 — 그때 기대 문장을 고친다.
- 단위 라디오 이름은 「월급·주급·일급·시급」, `exact: true` 로 고른다(「시급」이 다른 글자에도 들어 있다).
