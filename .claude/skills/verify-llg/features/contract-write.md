# 근로계약서 작성

월 임금 총액(또는 실수령액)이나 시간당 지급액과 근무형태(근무 요일·출퇴근·휴게·공휴일 근무 예정)를 넣으면 기본급(주휴 포함)·연장·휴일·연차 항목별 월 인정시간과 금액을 나누고, 만든 계약을 근로계약서 점검 규칙으로 다시 돌린 결과를 보여 준 뒤 엑셀·한글(hwpx)·PDF 로 내려받는다. 계산과 파일 생성은 모두 브라우저 안에서 한다(PDF 글꼴 파일 GET 하나만 서버로 간다).

## Sub-features

- `cw-required` 빈 입력 = 「입력이 필요합니다: 사업체명, 근로자 성명, 계약 시작일, 근무장소, 업무, 월 임금 총액」. 시나리오는 작성일 2026-02-26(시작일 3-01 전)을 넣는다 — 비우면 오늘이라 소급 작성(WRITTEN-TERMS)이 되먹임에 뜬다.
- `cw-uijeongbu` 의정부 주4 표본(261103 교정, #151 휴일 계수 교정) · 월·화·수·목 10:00~22:00 · 휴게 155분 · 공휴일 22일 · 월 2,600,000 = 기본급(잔액) 166.85시간 1,895,839원 · 연장 36.93시간 419,652원 · 휴일 18.64시간 211,788원 · 연차 6.4시간 72,721원 · 통상시급 11,362.67원 · 점검 되먹임 「손볼 항목이 없습니다」. 출처 `tests/unit/contract-write-design.test.ts`·`contract-write-check.test.ts`. #151 전(교정 표본 그대로)은 1,870,364 / 414,013 / 휴일 21.76시간 243,879 / 71,744 · 통상시급 11,209.99원이었다 — 공휴일 하루 8시간 넘는 1.4167시간이 연장 1.5 + 휴일 2.0 = 3.5배로 겹쳐 있던 것을 법정 2.0(연장 1.5 + 휴일 0.5)으로 고쳐 휴일 시간만 줄었다.
- `cw-rounding` 「100원 단위 올림」 = 1,895,700 / 419,700 / 211,800 / 72,800, 되먹임 손볼 항목 없음(#139 적대 검토 4 — 버림을 올림으로 바꿨다).
- `cw-absorb` 잔액을 「휴일근로수당」으로 = 휴일근로수당(잔액) 211,788원.
- `cw-files` 엑셀(PK)·한글(PK)·PDF(%PDF) 내려받기, 증거 폴더에 `contract-write-<폭>.<확장자>`.
- `cw-night` 퇴근 22:30 이면 「야간근로수당」 항목이 생긴다(22:00~22:30 × 0.5 × 주근무일 × 4.345).
- `cw-part` 「시급·일급 파트」 · 평일 11:00~17:00 · 휴게 30분 · 시간당 13,000원 · 공휴일 16일 = 기본급(잔액) 5.5시간 58,293원 · 주휴수당 1.1시간 11,658원 · 연차수당 0.25시간 2,683원 · 휴일근로수당 0.51시간 5,366원 · 합계 78,000원 · 통상시급 10,598.60원 · 되먹임 손볼 항목 없음. 출처 = 수원 파트 양식 「_2026」 a, `tests/unit/contract-write-part.test.ts`. 파트 hwpx 를 `contract-write-part-<폭>.hwpx` 로 남긴다.
- `cw-no-send` 입력값(총액·근로자 이름)이 실린 요청 0건.
- 화면에만 있고 드라이브하지 않는 것: 수습(감액 90% — 단순노무·1년 미만 기간제는 오류로 막음), 월 실수령액으로 넣기, 5명 미만. 기대값은 `tests/unit/contract-write-form.test.ts`.
- 오프라인판(HTML 1장): `npm.cmd run verify:contract-write-offline` — file:// 로 열어 월급·파트 금액, 세 파일 내려받기, 요청 0·콘솔 오류 0. `--keep <폴더>` 로 받은 파일을 남긴다.

## How to get to it (user POV)

- `/tools` 목록 「근로계약서 작성」, 또는 `/tools/contract-write`. 칸을 채우면 아래 「임금 구성」이 바로 바뀐다(버튼 없이).

## Driving it with verify.mts

- `node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON .claude/skills/verify-llg/scripts/verify.mts drive --feature contract-write [--base http://127.0.0.1:<포트>]`
- 하이드레이션을 기다린 뒤(「사업체명」 입력에 React props) 채운다. 결과는 `#cw-result` 글자 전체로 본다.
- 근무 요일 기본값은 월~금이라 「금」을 눌러 끈다.

## Gotchas

- 선택지 버튼 묶음을 `<label>` 로 감싸면 첫 버튼이 라벨 글자 전체를 이름으로 가져가 `getByRole('button', { name })` 이 못 찾는다(261103 실측 — 화면 읽기 프로그램에도 틀린 이름). Field 는 `<div>` 다.
- 「(잔액)」 표시는 항목 이름에 붙어 `innerText` 에서 공백 없이 나온다(「기본급(주휴 포함)(잔액)」).
- 「시급·일급 파트」로 바꾸면 잔액 항목이 기본급으로 돌아가고, 근무 요일 선택은 그대로 남는다(시나리오는 「금」을 다시 눌러 주5로 맞춘다).
- 파트 표의 「기본급」에는 「(주휴 포함)」이 붙지 않는다 — 주휴수당이 따로 줄로 나온다.
- 100원 단위 올림을 고르면 잔액은 기본급이 받는다(다른 항목을 고르면 오류). 올린 항목은 통상시급 × 시간 이상이라 점검 되먹임이 깨끗해야 한다 — 「산출근거-금액 정합」이 뜨면 결함이다.
