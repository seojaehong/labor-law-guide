# 근로소득 간이세액표 원천

실수령액 계산기(`/tools/take-home-pay`)가 쓰는 표의 원천이다. 화면이 읽는 것은
`src/lib/calc/wage-withholding-2026-02-27.ts` 이고, 그 파일은 이 CSV 에서
`node scripts/build-withholding-table.mjs` 로 만든다. 손으로 고치지 않는다.

## kr-wage-withholding-2026-02-27.csv

- 근거: 소득세법 시행령 [별표2] 근로소득 간이세액표 <개정 2026. 2. 27.> (제189조제1항 관련)
- 2026. 9. 30. 공포·10. 1. 시행 시행령에서도 별표2 표기가 같다(법제처, 2026-10-28 확인).
- 열: `lower_won,upper_won,fam1..fam11` — 월급여액(비과세·학자금 제외) 구간과 공제대상가족 수 1~11명 세액(원).
- 구간은 `[lower, upper)`(이상~미만). 646구간(770천원~10,000천원) 뒤 마지막 행 `lower = upper = 10,000,000` 은
  원문의 「10,000천원」 행, 곧 정확히 1,000만원이다.
- 원문의 「-」는 0 으로 적었다.
- UTF-8, LF, 머리 1행 + 데이터 647행. sha256 은 같은 이름의 `.sha256` 파일.

## 어디서 왔나

| 파일 | sha256 | 비고 |
|---|---|---|
| 별표2 원문 PDF(27쪽) | `f284aa58f948f0819d56ffab3139dc49b51305463ceaded85f1547de3c3359ab` | 이 CSV 는 이 PDF 의 글자를 뽑아 만들었다. 저장소에는 넣지 않았다 |
| 사무소 조견표 xlsx(시트 「세액표(2602)」) | `1517df7c6a999e0a65992f82c0428209ba50f0df5e6a45412bbc7efb5d70e77c` | 사무소가 만든 파생본(openpyxl, 2026-10-07). 독립 원문이 아니다. 647행·7,117칸이 CSV 와 같다(2026-10-28 대조) |
| 법제처 별표2 HWP 추출본 | — | 응답이 50,000자에서 잘려 앞 463행(~6,340천원)만 대조, 불일치 0 |

저장소 안의 시험(`tests/unit/calc-take-home-pay.test.ts`)은 이 CSV 의 해시·행 수(647)를 고정하고,
화면이 읽는 TS 표와 전 행·전 칸이 같은지, 구간이 끊기지 않는지, 가족 수·급여 양쪽으로 세액이 거꾸로 가지 않는지 본다.

## 표를 바꿀 때

1. 새 별표2 원문으로 CSV 를 다시 만들고(파일 이름에 개정일), 사무소 조견표와 전 칸을 대조한다. 몇 점만 맞춰 보는 것으로 갈음하지 않는다.
2. `.sha256` 을 새로 쓰고 생성 스크립트를 돌린다.
3. 별표2 제3호 자녀 공제 금액(`src/lib/calc/take-home-pay.ts`)도 같은 개정에서 바뀌었는지 확인한다.
